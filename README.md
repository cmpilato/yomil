# YOMIL - Your Obligations, Monitored, Informed, Logged

YOMIL (pronounced "YAHM-uhl") is a small, multiplatform application for
recurring bill reminders with the following features:

- scheduled bills with recurrence
- notifications for upcoming due dates
- manual reconciliation with a free-form note ("Paid online", "Paid with check
  #3465", etc.)
- permanent log of every reconciliation

It is deliberately *not* an account tracker, nor a mechanism by which to
actually pay bills.

For developer information, see [DEVELOPING.md](./DEVELOPING.md).
